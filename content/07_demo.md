## Полный демонстрационный вариант

### Артефакт Модуль и инструкция запуска
<!-- artifact: baseline_readme.md -->
```powershell
python -m demo.project run
python -m demo.project search --mode baseline --query "джаз минимализм"
python -m demo.project search --mode baseline --query "саксофон лаконичный"
```

Код: класс SearchEngine в demo/project.py. Первая команда воспроизводит данные и оценку; команда search показывает поведение объединённого интерактивного каталога и не пересчитывает validation. Для первого запроса возвращаются джазовые минималистичные карточки, для второго — пустой список. Полные ответы сохранены в demo/results/validation_baseline_detail.json.

Алгоритм: привести к нижнему регистру; извлечь токены; рассчитать частоты; применить IDF, обученный на train; нормировать векторы; вычислить сходство; удалить недопущенные карточки и нулевые совпадения; отсортировать по убыванию оценки и ID; оставить top-3.
<!-- endartifact -->

### Артефакт Итоговые метрики и интерпретация
<!-- artifact: baseline_findings.md -->
| Сегмент | Число запросов | Средняя NDCG@3 | Recall@3 |

| Буквальные | 6 | 1,00 | 1,00 |
| Синонимические | 6 | 0,00 | 0,00 |

Результаты рассчитаны demo/project.py. Для буквального запроса по джазу validation выдаёт P003, P004 и ещё одну частично совпавшую по стилю карточку; оценки релевантности 2, 1, 0. Для «саксофон лаконичный» неизвестны оба слова, выдача пуста.

Вывод: baseline работает на точном словаре, но не распознаёт заданные предметные синонимы. Следующая гипотеза — заменить известные синонимы каноническими терминами перед тем же TF-IDF. В validation лишь 12 запросов, поэтому представлены все 6 удачных и 6 неудачных случаев; это обоснованное уменьшение объёма относительно требования 10+10.
