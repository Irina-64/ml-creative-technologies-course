### Артефакт Сценарий показа
<!-- artifact: walkthrough.md -->
1. Запустить локальный API и проверить /health.
2. Отправить «саксофон лаконичный» и показать источник и допуск первых карточек.
3. Выбрать P001 через /feedback с action=select и actor=designer_demo. Показать recorded и model_updated=false.
4. Отправить пустую строку и показать HTTP 400 с empty_query.
5. Отправить «jazz minimalist» и показать no_matches.
6. Запустить контролируемый резервный режим и повторить «джаз минимализм». Показать fallback и сохранённый полезный результат.

Нормальный сценарий завершается сохранением выбора. Проблемные случаи объясняют, когда уточнить запрос и когда система работает ограниченно. Используются только созданные для демо макеты.
<!-- endartifact -->

### Артефакт Инструкция запуска и запись
<!-- artifact: run_and_record.md -->
```powershell
python -m demo.project run
python -m demo.record_demo
```

Вторая команда сама поднимает временный локальный HTTP-сервер, отправляет реальные запросы, сохраняет ответы и корректно останавливает его. Создаются demo/results/walkthrough.json, walkthrough.txt и walkthrough.cast. Формат cast содержит запись вывода терминала, которую можно воспроизвести совместимым проигрывателем asciinema; текстовая расшифровка не требует проигрывателя. В комплект включена также анимированная визуализация этой записи walkthrough.gif.

Для ручной демонстрации: `python -m demo.server --port 8765`. Для контролируемого отказа: `python -m demo.server --port 8766 --simulate-failure`. Это специально заданный отказ улучшения, а не доказательство обработки всех возможных аварий процесса или сети.
<!-- endartifact -->

### Артефакт Известные ограничения
<!-- artifact: limitations.md -->
Alpha использует 36 искусственных макетов, короткие русские описания и восемь соответствий словаря. Она не распознаёт визуальное содержание произвольного изображения, не подтверждает права и не доказывает экономию времени дизайнера. Скорость на промышленном архиве не измерена.

Сервис предназначен только для localhost. Нет аутентификации, графического интерфейса, промышленного журналирования, устойчивого многопользовательского хранилища и процесса утверждения правок. Нельзя выставлять этот http.server в открытую сеть. Указание роли в JSON не подтверждает полномочия человека.

При отказе словаря буквальный поиск остаётся доступен; синонимические запросы могут потерять результат. Пользователь видит fallback и может переформулировать запрос или перейти к ручному просмотру. При полном отказе процесса API недоступен: этот класс отказа не устраняется текущим fallback.
<!-- endartifact -->
