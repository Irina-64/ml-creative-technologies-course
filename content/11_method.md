## Граница компонента

Минимальный модуль должен принимать понятный вход и возвращать структурированный результат. Контракт описывает типы, обязательные поля, пределы и ошибки. Это позволяет проверять модуль независимо от интерфейса. Для генеративного ассистента дополнительно фиксируются шаблон запроса, источник контекста и правила проверки фактов; выбранный поисковый трек не обязан искусственно добавлять генерацию.

В демо моделью служит статистическое TF-IDF-представление текста, дополненное инженерией знаний. Оценка score выражает сходство векторов, а не вероятность правильности или юридическую допустимость изображения. Это различие необходимо объяснить пользователю и сохранить в документации.

## Развёрнутый порядок выполнения

### Шаг 1 Контракт

Опишите валидный запрос, пустой ввод, неверный тип, превышение длины и структуру результата. Решите, чем отсутствие совпадений отличается от ошибки. Если оба случая возвращают пустой список без статуса, пользователь не сможет выбрать следующий шаг.

### Шаг 2 Сквозная реализация

Соедините чтение каталога, построение модели, поиск и сериализацию ответа без ручного изменения результата. Проверьте один запрос в новом процессе. Ноутбук допустим для исследования, однако сдаваемый модуль должен иметь воспроизводимую точку входа.

### Шаг 3 Конфигурация

Вынесите параметры k, ограничения и версию в отдельный файл. В выбранном локальном варианте секретов нет. Для проекта с API храните ключ отдельно от репозитория и показывайте пример конфигурации без значения секрета. Изменение параметров фиксируйте как новую конфигурацию эксперимента.

### Шаг 4 Набор сложных входов

Проверьте обычный запрос, известный синоним, неизвестный язык, пустую строку, слишком длинный текст и неверный тип. Для генерации добавьте запросы с отсутствующими фактами и конфликтующими инструкциями. Результат теста должен содержать ожидаемое и фактическое поведение.

### Шаг 5 Примеры запуска

Сохраните конкретные запросы и ответы, модель и версию данных. Обрезая большой ответ для отчёта, явно напишите, какие поля опущены; машиночитаемый файл должен оставаться полным. Не заменяйте фактический вывод удобным выдуманным JSON.

### Шаг 6 README и проверка

Напишите установку, команды и ожидаемый результат так, чтобы другой студент запустил модуль без подсказок автора. Укажите рабочую папку, версию Python и отсутствие внешних зависимостей. Проверьте инструкции в отдельном запуске.
