## Запуск сквозного демо

Нужен Python 3.10 или новее. Для запуска проекта и расчётов сторонние пакеты и API-ключи не требуются. Выполняйте команды из корня этого репозитория:

```shell
python -m demo.project run
python -m demo.eda
python -m unittest demo.test_project -v
python -m demo.record_demo
python -m demo.server --port 8765
```

Сервер слушает только `127.0.0.1`; остановка — Ctrl+C. Ручные запросы и контракт приведены в ЛР 11. Повторная генерация перезаписывает только данные и результаты учебного примера. Не сохраняйте там единственную копию своего исследования.

В основе примера — TF-IDF по описаниям плюс предметный словарь. На 12 искусственных validation-запросах baseline даёт NDCG@3 0,50, улучшение 1,00. Это демонстрация процесса сравнения, а не доказательство качества на настоящем архиве. В комплекте 42 исходные записи, после очистки 36 уникальных геометрических макетов; реальный архив студии не использован.

Интервью, разметчики и пользовательские сессии в письменных образцах симулированы и явно обозначены. В своей работе студент должен получить собственные свидетельства или согласовать заменяющий метод. Вычислительные таблицы, тесты и HTTP-ответы получены реальным запуском кода.

Запись API: [анимация фактических ответов](demo/results/walkthrough.gif), [текстовая расшифровка](demo/results/walkthrough.txt), [запись терминала](demo/results/walkthrough.cast). Это автоматическая демонстрация, не исследование с участниками.

## Устройство репозитория

- `labs/01` — `labs/16` — самостоятельные методические указания и образцы сдаваемых документов.
- `demo/` — общий запускаемый код, данные, графики, результаты и тесты.
- `source_prompts/` — выделенные исходные задания, использованные для разработки каждой ЛР.
- `content/` — редактируемые исходники развёрнутых текстов.
- `tools/` — средства сборки документов и демонстрационной презентации.
- `assets/` — изображения графиков для Word; исходные SVG находятся в результатах EDA.

Для пересборки Word нужны python-docx и Pillow; это зависимости авторской сборки, а не студенческого демо. Скрипт build_materials.py при первичной сборке читает исходную методичку из родительской папки; в опубликованном комплекте использует сохранённые source_prompts/requirements.json. Для PPTX нужен комплект @oai/artifact-tool. Проверка Word выполнялась отдельным скрытым экземпляром Microsoft Word с просмотром экспортированных страниц; временные файлы проверки в репозиторий не включаются.

Репозиторий создан закрытым для предварительной проверки материалов. Публичная лицензия на весь курс не назначена; изменение видимости и условий распространения остаётся за владельцем.
