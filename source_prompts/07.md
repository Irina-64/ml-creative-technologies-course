Лабораторная работа 7. Baseline для проектной задачи

Связь с лекциями. Лекция 4

Формируемые компетенции. ПК-1, ПК-1.1

Цель. Получить простую воспроизводимую нижнюю границу качества, с которой будут сопоставляться последующие улучшения.

Исходная ситуация

Для поиска референсов baseline может ранжировать материалы по совпадению ключевых слов. Для классификации жанров — выбирать самый частый класс. Такой результат скромен, но честно показывает исходную точку.

Порядок выполнения

1. Выберите наиболее простой содержательно оправданный подход: правило, частотную модель, классический ML или нулевой retrieval.

2. Зафиксируйте данные, split, seed, версию окружения и команду запуска.

3. Реализуйте baseline как отдельный модуль, а не как необъяснимую ячейку notebook.

4. Рассчитайте метрики, согласованные с ЛР-3, и сохраните результаты в машиночитаемом виде.

5. Отберите не менее десяти корректных и десяти проблемных результатов либо обоснуйте меньший объём для малого набора.

6. Сформулируйте, что именно baseline не умеет и какую гипотезу имеет смысл проверять далее.

Демонстрационный вариант выполнения

Ниже показан возможный результат по каждому шагу задания на сквозном учебном кейсе. Используйте его как ориентир уровня детализации, а не как готовое решение.

1. Выбран baseline: ранжирование по совпадению слов в названии, описании и тегах. Он проще embeddings-поиска и объясним для первого сравнения.

2. Зафиксированы dataset v0.2, 40 тестовых запросов, seed 42 и файл configs/baseline.yaml; окружение указано в requirements.txt.

3. Реализация вынесена в src/baseline.py, запуск — `python -m src.baseline --config configs/baseline.yaml`; notebook используется только для просмотра результатов.

4. На 40 запросах baseline дал NDCG@10 = 0,41, Recall@10 = 0,62 и среднее время ответа 0,2 секунды; таблица results/baseline_metrics.json сохранена.

5. Подборка содержит 10 удачных и 10 неудачных ответов. Пример ошибки: запрос «ночной электронный концерт» находит слово «концерт», но игнорирует настроение.

6. Вывод: baseline не понимает смысловые близкие запросы и многоязычные формулировки; следующая гипотеза — добавить text embeddings, не меняя набор запросов.

Что сдать

Код baseline; README с командой запуска; фиксированные настройки; таблица метрик; подборка удачных и ошибочных случаев.

Критерии приёмки

Baseline запускается повторно; он действительно проще будущего решения; метрики корректны для трека; примеры показывают границы, а не только успех.

Типичные ошибки

Называть baseline сложную нейросеть; менять данные между запусками; использовать test для настройки; сравнивать несопоставимые метрики.
