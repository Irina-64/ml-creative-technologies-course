Лабораторная работа 4. Реестр данных и Data Card

Связь с лекциями. Лекции 2–3

Формируемые компетенции. ПК-1.1, ПК-3.1

Цель. До обучения модели оценить происхождение, пригодность, права и ограничения источников данных.

Исходная ситуация

Для коллекции изображений важно различать открытый набор, собственный архив студии, материалы с неясной лицензией и синтетические изображения; эти группы нельзя молча смешивать.

Порядок выполнения

1. Создайте реестр всех потенциальных источников: владелец, ссылка, тип данных, объём, лицензия, дата получения, допустимое применение.

2. Опишите схему данных, целевую единицу анализа, доступные метаданные и наличие персональных либо чувствительных данных.

3. Оцените репрезентативность: какие жанры, языки, авторы, периоды и пользовательские сценарии представлены хуже других.

4. Подготовьте Data Card v1: мотивация, состав, сбор, обработка, предполагаемое использование, ограничения и ответственность.

5. Определите стратегию train/validation/test так, чтобы связанные объекты не попадали по разные стороны разделения.

6. Составьте plan B для недоступного, платного или юридически сомнительного источника.

Демонстрационный вариант выполнения

Ниже показан возможный результат по каждому шагу задания на сквозном учебном кейсе. Используйте его как ориентир уровня детализации, а не как готовое решение.

1. Реестр: 800 постеров студии, 300 изображений с открытой лицензией, 100 материалов с неясными правами. Последняя группа исключена из обучения и демонстрации.

2. Схема карточки: id, файл, автор, год, язык, жанр, описание, лицензия, серия. Единица анализа — отдельный постер; персональные данные авторов не сохраняются сверх открытой подписи.

3. Аудит выявил недостаток театральных афиш и англоязычных описаний. Эти сегменты внесены в раздел ограничений Data Card.

4. Data Card v1 описывает назначение набора, способ сбора, 1 100 разрешённых изображений, лицензионные ограничения, план удаления неразрешённого материала и владельца данных.

5. Split выполнен по автору и серии: 770 карточек train, 165 validation, 165 test. Работы одного автора находятся только в одной части набора.

6. Plan B: при недоступности архива студии применяется только открытый учебный набор из 300 карточек; демонстрация использует локальный индекс без внешнего API.

Что сдать

Реестр данных; Data Card v1; схема данных; стратегия split; черновик инструкции разметки; план B.

Критерии приёмки

Происхождение и права понятны; синтетические данные помечены; split исключает утечку; ограничения не спрятаны в примечаниях.

Типичные ошибки

«Данные из интернета» как источник; смешение лицензий; случайное разделение кадров одного ролика; отсутствие сведения о том, может ли набор попасть в репозиторий.
